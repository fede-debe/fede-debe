## **About me** ℹ️

Android developer who works across the whole stack of a mobile feature: the app, the shared Kotlin Multiplatform (KMP) library and the Go backend-for-frontend (BFF), from the first question to the screen the user sees.

**AI-assisted engineering.** I use AI as part of how I engineer, not as a shortcut:

- I review everything an AI produces before it goes out. The work stays mine.
